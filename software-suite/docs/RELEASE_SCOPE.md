# Release scope

## Suggested first release
1. Authentication foundation (with email verification/password reset completed before public launch)
2. Workspace creation and Business Profile settings
3. Customers and enquiries
4. Responsive dashboard using real data
5. Secure tenant isolation and initial roles
6. Basic import, invoices and subscription work after their own acceptance criteria are completed

## Explicitly not represented as complete in this starter
- Google/Microsoft OAuth
- Email verification delivery and password recovery
- Razorpay/other payments
- Production subscription management and trial enforcement
- Invoice PDF generation and tax/legal compliance
- CSV/XLSX import pipeline
- Cloud drive connectors
- Team invitation delivery and fine-grained permissions
- Complete industry-specific operational modules
- Production-grade session refresh/revocation, audit logging and observability

Build incrementally. Do not expose unfinished features as active to customers.
